qsengine, a quantum circuit simulator for Python

import qsengine

qc = qsengine.QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)

counts = qc.run(shots=1000, seed=1)
print(counts)
# {'00': 513, '11': 487}

print(qc.probabilities())
# 0.5 for 00, 0.5 for 11

print(qc)
# q0: ──H──●──
#          │
# q1: ─────X──

# the same circuit, each backend
cpu = qc.run(backend="cpu")
gpu = qc.run(backend="gpu")

# three qubits: a GHZ state
ghz = qsengine.QuantumCircuit(3)
ghz.h(0)
ghz.cx(0, 1)
ghz.cx(1, 2)
print(ghz.statevector())

qsengine questions

What people ask before they install it.

Ask on GitHub

Does qsengine need a GPU?

No. qsengine runs on any CPU and uses a GPU when one is present, through Vulkan, DirectX 12 or Metal.

How large a circuit can qsengine run?

Up to 30 qubits. Memory doubles with every qubit: 20 qubits take 16 MiB and 30 take 16 GiB.

Which Python versions work?

CPython 3.9 and newer, with one wheel per platform.
