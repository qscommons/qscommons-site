import qsengine

qc = qsengine.QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)

counts = qc.run(shots=1000, seed=1)
print(counts)
# {'00': 513, '11': 487}

print(qc.probabilities())
# 0.5 for 00, 0.5 for 11

print(qc)
# q0: ──H──●──
#          │
# q1: ─────X──

# the same circuit, each backend
cpu = qc.run(backend="cpu")
gpu = qc.run(backend="gpu")

# three qubits: a GHZ state
ghz = qsengine.QuantumCircuit(3)

Questions

What people ask before they install anything.

Ask on GitHub

Are the tools free to use?

Yes. Every project is under the MIT licence, so you can use it in teaching, research and commercial work.

Does quantum simulation need a GPU?

No. qsengine runs on any CPU and uses a GPU when one is present, through Vulkan, DirectX 12 or Metal.

How large a quantum circuit can qsengine run?

Up to 30. Memory doubles with every qubit: 20 qubits take 16 MiB and 30 take 16 GiB.

Which Python versions work?

CPython 3.9 and newer, with one wheel per platform.

Can I propose a new tool?

Yes. Open an issue that describes the tool and who it is for. It joins once it meets the same standards as qsengine.

qscommons maintainers and contributors

One maintainer today: kaiwave, who started qscommons to give qsengine a home bigger than a personal project. Every change is reviewed in public on GitHub, open to anyone.
