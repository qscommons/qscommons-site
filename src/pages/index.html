Questions

What people ask about qscommons.

Ask on GitHub

Are the tools free to use?

Yes. Every project is under the MIT licence, so you can use it in teaching, research and commercial work.

Where do I start?

With qsengine, the first project: see what it does, then pip install qsengine.

Can I propose a project?

Yes, whether it is a tool, a learning site, a hardware guide or research. Open an issue that says what it is and who it is for. It joins once it meets the same standard as every other project.
